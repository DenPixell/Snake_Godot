# Поза рук

Поза рук, камера и место Game Boy хранятся в сцене `console/hold_pose.tscn`. Игра берёт их оттуда как есть, поэтому позу можно выставить мышкой прямо в редакторе.

## Как поменять позу

1. Откройте `console/hold_pose.tscn` двойным щелчком в панели FileSystem.
2. В дереве сцены раскройте `Hands → Sketchfab_model → … → Object_5 → Skeleton3D` и выделите `Skeleton3D`.
3. На панели инструментов 3D-вида включите **Режим редактирования** (Edit Mode) — кнопка появляется, когда выделен Skeleton3D. На суставах появятся точки.
4. Щёлкните по суставу, нажмите **E** (поворот) и тяните за цветные кольца. **Q** — обычный выбор, **Cmd+Z** — отменить.
5. Чтобы посмотреть глазами игрока: выделите `Camera3D` и включите галочку **Предпросмотр** в левом верхнем углу 3D-вида.
6. Сохраните сцену: **Cmd+S**.
7. Пересчитайте нажатия больших пальцев под новую позу:

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . -s tools/thumb_poses.gd
```

Анимации из модели рук отключены при импорте (`assets/hands/scene.gltf.import`, `animation/import=false`): иначе редактор показывает поверх позы готовую анимацию модели, например кулаки.

## Имена костей

| Кость | Что это |
|---|---|
| `Shoulder_2` | плечо |
| `Forearm` | предплечье |
| `Hand` | кисть |
| `Finger_5` | большой палец |
| `Finger_4` | указательный |
| `Finger_3` | средний |
| `Finger_2` | безымянный |
| `Finger_1` | мизинец |

`.L` — левая рука, `.R` — правая. У пальцев `.1` — фаланга у ладони, дальше к кончику `.2`, `.3`.

## Что ещё можно двигать

- `GameBoyAnchor` — где Game Boy в руках. Модель внутри него (`Preview`) нужна только для редактора: в игре её заменяет настоящий Game Boy с экраном.
- `Camera3D` — глаза игрока.

## Как устроены нажатия

В покое пальцы стоят ровно так, как в сцене. При нажатии большой палец доворачивается к кнопке. Эти довороты лежат в `console/thumb_poses.tres`, их считает `tools/thumb_poses.gd`: подбирает углы фаланг так, чтобы кончик пальца встал на кнопку и чуть её вдавил, а сустав не ушёл в корпус.
