# План и устройство проекта

## Этапы

1. **Логика змейки** — поле, движение, предметы, эффекты, сложности. Без графики, с тестами.
2. **Экран Game Boy** — ЖК-отрисовка в 2D, меню Game Boy, лидерборд. Игра уже играбельна в окне.
3. **3D-сцена** — Game Boy и руки, свет, камера, экран на корпусе.
4. **Главное меню** — комната, надпись SNAKE, переход к Game Boy.
5. **Настройки** — громкость, переназначение клавиш, язык.
6. **Звук** — эмбиент и звуки Game Boy.
7. **Сборки** — macOS и Windows.
8. **Android** — вертикальный экран, касания по кнопкам Game Boy.

## Папки

```
game/      логика змейки, не знает про графику и узлы сцены
screen/    всё, что рисуется на ЖК-экране Game Boy
console/   3D Game Boy, руки, камера
menu/      главное меню и меню паузы
audio/     эмбиент и звуки
autoload/  глобальные синглтоны: настройки, лидерборд
tests/     тесты логики, запускаются без окна
docs/      требования и план
```

## Главные решения

- **Логика отделена от графики.** `game/` — обычные классы на `RefCounted`, без узлов. Экран только читает их состояние и рисует. Так логику можно тестировать без запуска сцены, а Android-версия использует тот же код.
- **Время в логике передаётся снаружи** (`tick(delta)`). Пауза — это просто «не вызывать tick». Тесты двигают время сами, без ожидания.
- **Случайность через `RandomNumberGenerator` с сидом.** В тестах сид фиксирован, поэтому результат повторяется.
- **Экран рисуется в `SubViewport`**, а 3D-корпус показывает его как текстуру через шейдер ЖК. В Android-версии тот же экран.
- **Язык — GDScript**, а не C#: проще и надёжнее экспорт на Android.
