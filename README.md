# Snake

Змейка на старом потёртом Game Boy в тёмной комнате. Вид от первого лица: руки держат приставку, большие пальцы жмут кнопки, свеча едва освещает стол. Хоррор-атмосфера без скримеров — только темнота и низкий гул.

Сделано на Godot 4.7 (GDScript).

## Запуск

**Готовая сборка** — скачайте архив для своей системы со страницы релизов.

| Система | Файл | Как запустить |
|---|---|---|
| macOS | `Snake.zip` | Распакуйте. При первом запуске — правый щелчок по `Snake.app` → «Открыть» (приложение не подписано сертификатом Apple). |
| Windows | `Snake.exe` | Запустите. Если SmartScreen предупредит — «Подробнее» → «Выполнить в любом случае». |
| Linux | `Snake.x86_64` | `chmod +x Snake.x86_64 && ./Snake.x86_64` |

**Из исходников** — откройте папку проекта в Godot 4.7 и нажмите F5.

## Управление

Всё переназначается в настройках.

| Кнопка Game Boy | По умолчанию | Действие |
|---|---|---|
| Крестовина | W A S D | движение, выбор в меню |
| A | левая кнопка мыши | выбрать; в игре — пауза |
| B | правая кнопка мыши | назад; в игре — продолжить после отсчёта |
| Start | колесо мыши (нажатие) | в меню Game Boy |
| — | Esc | меню паузы: продолжить, настройки, главное меню |
| — | F11 | полный экран |

## Правила

Поле 20 × 25. Удар о стену, о себя или о кирпич — конец игры. На поле всегда один объект, пропустить его нельзя.

| Объект | Что делает |
|---|---|
| Точка | +1 к длине, +1 к счёту |
| Большое яблоко | +2–5 к длине, +1 к счёту |
| Гнилое яблоко | управление наоборот на 5 секунд |
| Гнилой банан | слепота на 5 секунд: видно только около головы |
| Молния | +3 к скорости на 5 секунд |
| Кирпич | ставит стену на поле навсегда (никогда не перед головой и не так, чтобы отрезать часть поля) |

Повторный эффект добавляет ещё 5 секунд. Скорость растёт с каждым объектом. Победа — когда змейка займёт всё поле.

| Сложность | Ловушки |
|---|---|
| Easy | нет |
| Normal | после ловушки три обычные точки, пока действует эффект — новых ловушек нет |
| Hard | в любой момент |

Рекорды Normal и Hard хранятся локально, имя — три буквы, как в аркадах.

## Устройство проекта

```
game/      логика змейки без графики: поле, предметы, эффекты, сложности, рекорды
screen/    ЖК-экран Game Boy: отрисовка, меню приставки, шейдер экрана
console/   3D: Game Boy, руки, камера, свеча, сцена позы рук hold_pose.tscn
menu/      главное меню, пауза, настройки, обучение, заставка
audio/     синтезатор и все звуки (звуковых файлов нет — всё генерируется)
autoload/  настройки, рекорды, звуки меню, переводы
tests/     тесты логики
tools/     инструмент пересчёта нажатий больших пальцев
docs/      требования, план, как менять позу рук
assets/    модели (авторы — в CREDITS.md)
```

Логика игры (`game/`) не знает про графику: экран только читает её состояние. Поэтому её можно тестировать без запуска сцены.

## Тесты

## Сборка

Нужны шаблоны экспорта Godot 4.7.2 (Editor → Manage Export Templates). Настройки для macOS, Windows и Linux — в `export_presets.cfg`.

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --export-release "macOS" build/macos/Snake.zip
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --export-release "Windows" build/windows/Snake.exe
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --export-release "Linux" build/linux/Snake.x86_64
```
